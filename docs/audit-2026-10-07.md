# Follow-up audit — 7 October 2026

## Fixed
- Removed automatic Book role promotion when visiting Users.
- Deny unknown roles at the staff UI guard; this is not server authorization.
- Apply Dashboard search query on Accounts, including subsequent URL changes.
- Removed generated dashboard amounts and hardcoded fallback event lists. Missing market totals display an em dash.
- Bet Lock no longer loads unvalidated global localStorage or pretends local settings enforce server restrictions. Controls are disabled with an unavailable explanation until a real service is connected.
- Legacy password comparison is exact; a failed bcrypt comparison can never fall back to accepting the hash itself.

## Validation
- Production build and application TypeScript check passed for the UI changes.
- Role allowlist and amount formatting regression tests pass.
- Final password comparison change is type-checked and rebuilt before publication.
- No live financial transactions or user changes executed.

## Unresolved dependencies and findings
- Supabase connected project listing returned no projects, so live schema, RLS, authentication and wallet enforcement cannot be inspected or updated.
- Current login performs credential comparison in the client and session role is stored locally. Secure server authentication and hierarchy authorization are required; tightening the UI guard is not a substitute.
- The database adapter can fall back to browser mock data on network/schema errors. Reports can silently convert failures to empty arrays and are limited to 500 rows. These paths need integration work and live backend verification.
- Sports providers are mock functions. Authorized provider credentials and API contracts are required for live odds, settlement, casino and TV.
- Market locks require server persistence and enforcement at bet placement.
- Remaining report calculations, atomic bet placement, concurrency, complete ledger export and mobile/desktop visual parity are not certified.

Do not interpret these fixes as completion of all platform issues.
